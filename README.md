## 1. Audit Triggers

| Entity / Audit | When It Applies | Source of Requirement |
|---|---|---|
| Statutory audit (company) | Every company, regardless of size | Companies Act, 2013, ss. 139 and 143 |
| CARO 2020 report | Most companies; some small companies exempt | CARO 2020 |
| Tax audit | Business turnover > ₹1 crore (₹10 crore if ≥95% digital); profession receipts > ₹50 lakh | Income-tax, s. 44AB |
| LLP audit | Turnover > ₹40 lakh or contribution > ₹25 lakh | LLP rules |
| Trust / society audit | When claiming income-tax exemption | Income-tax law |
| GST audit / annual return | GST-registered businesses | GSTR-9, GSTR-9C |
